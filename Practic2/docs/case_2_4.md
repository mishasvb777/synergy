# Кейс-задача 2.4 — Аналитический обзор класса WORKER

## Атрибуты (свойства)

В классе `WORKER` хранятся:

- `lastNameAndInitials` — фамилия и инициалы;
- `position` — занимаемая должность;
- `salary` — заработная плата;
- `hireYear` — год поступления на работу.

Эти атрибуты покрывают требования задания и позволяют вычислять стаж в годах.

## Методы (функции)

Реализованы:

- функции-конструкторы `NewDefaultWorker`, `NewWorker`, `NewWorkerShort`;
- методы изменения полей (`set...`);
- методы доступа (`get...`);
- прикладные методы:
  - `ExperienceYears(currentYear)` — расчет стажа;
  - `HasExperienceGreaterThan(years, currentYear)` — проверка условия отбора;
  - `DisplayString()` — форматированный вывод.

## Абстракция

Класс `WORKER` описывает общий образ сотрудника организации и скрывает детали внутреннего представления данных за публичным интерфейсом.

## Инкапсуляция

Поля класса приватные. Доступ к ним осуществляется через методы. Для критичных полей добавлена валидация:

- зарплата не может быть отрицательной;
- год приема ограничен допустимым диапазоном.

Примечание: в Go нет деструктора в классическом понимании, управление памятью выполняется автоматически сборщиком мусора.

## Наследование

В базовой реализации наследование не применялось, так как требований к иерархии не было. При расширении модели возможно выделить базовый класс `PERSON` и унаследовать от него `WORKER`.

## Полиморфизм

В текущей версии не использовался. Для сложной предметной области можно ввести наследников:

- `ManagerWorker`;
- `EngineerWorker`;
- `SupportWorker`.

Тогда общие интерфейсы можно вызывать полиморфно.

## Соответствие требованиям

Решение соответствует кейсу 2.3:

- отдельный модуль с описанием и реализацией класса;
- использование динамического списка (`slice`) для хранения набора объектов;
- ввод данных с клавиатуры;
- вывод сотрудников по условию стажа;
- сообщение об отсутствии подходящих сотрудников.

## Тестирование

Подготовлен файл `pkg/worker/worker_test.go` с проверками:

- корректности конструкторов;
- расчета стажа;
- валидации некорректной зарплаты и года приема.
