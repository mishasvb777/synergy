# Кейс-задача 2.3 — Реализация класса WORKER

## Постановка

Необходимо описать класс `WORKER` с полями:

- фамилия и инициалы работника;
- должность;
- зарплата;
- год поступления на работу.

И реализовать программу, которая:

- считывает данные работников с клавиатуры;
- выводит фамилии работников, чей стаж больше заданного пользователем значения;
- выводит сообщение, если таких работников нет.

## Что реализовано

- Реализация выполнена на Go.
- Сущность `WORKER` вынесена в отдельный модуль `pkg/worker/worker.go`.
- Для инициализации предусмотрены функции-конструкторы:
  - `NewDefaultWorker()`;
  - `NewWorker(...)`;
  - `NewWorkerShort(...)`.
- Добавлены методы изменения и чтения полей, а также методы расчета и проверки стажа.
- В `cmd/worker_app/main.go` используется динамический список через `slice` (`[]worker.WORKER`).
- Реализован диалоговый ввод, фильтрация по стажу и вывод результата.

## Результат

Программа компилируется и выполняет все действия, требуемые в задании 2.3.
