# Производственная практика — кейс-задания

Этот репозиторий содержит выполненные кейс-задания по производственной практике:

- анализ организации (кейс 2.1 и 2.2);
- реализация программы с классом `WORKER` (кейс 2.3);
- аналитический обзор реализации и ООП-подхода (кейс 2.4);
- предложения по улучшению решения (кейс 2.5);
- итоговый отчет по практике.

## Структура проекта

- `docs/case_2_1.md` — сведения об организации;
- `docs/case_2_2.md` — анализ структуры и цифровой зрелости;
- `docs/case_2_4.md` — аналитический обзор по классу `WORKER`;
- `docs/case_2_5.md` — предложения по устранению выявленных проблем;
- `docs/report.md` — итоговый отчет о практике;
- `go.mod` — конфигурация Go-модуля;
- `pkg/worker/worker.go` — модуль `WORKER` (структура и методы);
- `cmd/worker_app/main.go` — консольное приложение;
- `pkg/worker/worker_test.go` — автотесты.

## Сборка и запуск (Windows, Go)

### Приложение

```bash
go run ./cmd/worker_app
```

### Тесты

```bash
go test ./...
```
