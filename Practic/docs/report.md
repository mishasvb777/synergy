# Отчет о прохождении производственной практики

## 1. Цель практики

Закрепить теоретические знания и получить практические навыки анализа организации, проектирования программных компонентов и разработки прикладного решения на языке Go.

## 2. Выполненные виды работ

1. Изучены требования по охране труда, технике безопасности, пожарной безопасности и санитарным нормам.
2. Выполнены кейс-задачи 2.1–2.5.
3. Систематизирован собранный материал.
4. Оформлен настоящий отчет.

## 3. Результаты кейс-задач

### 3.1 Кейс 2.1

Собраны и структурированы открытые сведения об организации (наименование, организационно-правовая форма, услуги, территориальное размещение, внешняя среда).

### 3.2 Кейс 2.2

Проведен анализ организационной структуры, функциональных элементов, сильных и слабых сторон, а также уровня цифровой зрелости.

### 3.3 Кейс 2.3

Разработана консольная программа на Go:

- класс `WORKER` размещен в отдельном модуле;
- реализованы функции-конструкторы и методы изменения/отображения;
- данные сотрудников хранятся в динамическом списке (`slice`);
- выполнен ввод с клавиатуры;
- реализован вывод сотрудников по критерию стажа;
- добавено сообщение при отсутствии подходящих записей.

### 3.4 Кейс 2.4

Подготовлен аналитический обзор по критериям ООП: атрибуты, методы, абстракция, инкапсуляция, наследование, полиморфизм, тестирование и документация.

### 3.5 Кейс 2.5

Предложены улучшения: усиленная валидация, разделение на слои, сохранение данных, расширенная аналитика, интеграция CI и развитие тестовой базы.

## 4. Использованные технологии

- Go 1.25;
- стандартная библиотека Go (`bufio`, `time`, `testing`, `strconv` и др.).

## 5. Вывод

В ходе практики получены навыки:

- анализа организации на основе открытых источников;
- проектирования класса в парадигме ООП;
- разработки, тестирования и документирования консольного приложения.

Практическая цель достигнута, требования кейс-заданий выполнены.
